# 售后进度可视化 Demo 走查记录

> 产品没有写需求文档，直接丢过来一个 H5 demo。以下是对 demo 的走查记录。

## 页面 1：售后单列表

- 列表项展示：商品缩略图、售后类型（仅退款/退货退款）、状态标签（审核中/退货中/退款中/已完成）。
- 点击列表项进入详情页。

## 页面 2：售后详情（demo 重点）

- 顶部是一个四步进度条：提交申请 → 商家审核 → 买家退货/物流揽收 → 退款到账。
- 当前步骤高亮，已完成步骤打勾；每一步下面有时间戳。
- 「买家退货」这一步展示了快递单号和物流轨迹的最近一条记录，点击可展开完整轨迹。
- 「退款到账」步骤展示预计到账时间（demo 里写死为「1-3 个工作日」）。
- 页面底部有「催一催」按钮，点击后 toast 提示「已提醒商家尽快处理」。

## demo 未覆盖的部分（走查时观察）

- 仅退款（无需退货）时进度条怎么变，demo 没演示。
- 「催一催」点击后商家侧收到什么，demo 没体现。
- 售后被拒绝的展示状态缺失。
